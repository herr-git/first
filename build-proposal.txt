1. DECISIONS ALREADY MADE (do not reopen)
----------------------------------------------------------------------
- Static site (plain web pages, no server), hosted free on GitHub Pages.
- A scheduled script on GitHub Actions fetches data every 15 minutes and saves it as data files. The site only reads those files.
- The browser must NEVER call data providers directly (providers block this, and it would expose limits).
- No database, no login, no accounts, no paid services. Monthly cost must be zero.
- Fund list: 6 funds, kept in one editable text/JSON file:
  - Bitcoin: IBIT, FBTC, GBTC
  - Ethereum: ETHA, ETHE
  - Zcash: ZCSH (Grayscale Zcash trust)
  (The original backlog says 8 funds. Only 6 were provided. Build for 6. Adding more must be a one-line edit to the fund file.)
- Tokens: top 10 by 24-hour trading volume, stablecoins included. Pick them once on first run from CoinGecko, then FREEZE the list in a file. Do not re-rank automatically.
- Fund prices may be delayed 15 minutes. Show a "delayed 15 minutes" label.
- Fund market value = price times shares outstanding. Shares outstanding is typed by hand into the fund file with an "as of" date and a source link. Label fund market value "approximate".
- Yearly fee is also typed by hand into the fund file with source link and "as of" date. Look the numbers up on each fund provider's page. Do not use numbers from memory. The owner will verify them.
- Bid and ask (highest buyer price and lowest seller price): show for funds when available, otherwise show "not available". Missing bid or ask must never cause an error. For tokens, show price only (free summary sources have no bid/ask).
- Display currencies: euro (EUR), US dollar (USD), pound (GBP), Australian dollar (AUD), yen (JPY). No tokens as display units.
- Saving a mock portfolio: browser storage (localStorage) only. No IP address storage, no privacy notice needed.
- Legal review is assumed done. Still show the "not financial advice" banner on every page without scrolling.
- Real trading inside the product is out of scope.

----------------------------------------------------------------------
2. DATA SOURCES (free only)
----------------------------------------------------------------------
- Tokens: CoinGecko free API. One request returns top coins sorted by volume with price, market value, volume. History: CoinGecko daily history for the last 30 days.
- Funds: Yahoo Finance through the yfinance Python library (unofficial, may break; acceptable for a private demo). Fund history: same source, daily closing prices.
- Fallbacks if Yahoo fails for a fund: Stooq (end-of-day only) or Twelve Data / Finnhub / Alpha Vantage free plans. Note their request limits before using them.
- Exchange rates: Frankfurter (European Central Bank rates, free, no key). Current and historical.
- Google Finance: do NOT use. It has no official access for outside apps.
- Known free-data limits:
  - Fund prices are delayed about 15 minutes.
  - Fund bid/ask is often empty or zero outside market hours.
  - Shares outstanding and yearly fee are not in price feeds (hand-typed).
  - ZCSH likely trades over the counter and may have patchy or no data. If it fails, show "not available" and move on. It must not block the demo.
  - Crypto volume is not fully reliable and sources disagree. Add a short note on the page.

----------------------------------------------------------------------
3. DATA FILE RULES
----------------------------------------------------------------------
- Keep ALL sample and live data in files under /data, in the SAME shape, so going live means replacing file contents, not rebuilding pages.
- Files (suggested):
  - data/funds-config.json: ticker, name, type (Bitcoin/Ethereum/Zcash), shares outstanding, shares as-of date, yearly fee, fee as-of date, source links. Editable without changing code.
  - data/tokens-config.json: the frozen top 10 tokens and a stablecoin flag for each.
  - data/latest.json: latest prices, market value, volume, bid, ask, plus a "last updated" time per table.
  - data/history.json: 30 days of daily closing prices for all assets.
  - data/fx.json: exchange rates.
  - data/country-platforms.json: which trading platform serves which country (hand-edited).
- If a source fails: keep the last good data, record the failure in a log file, and show a "delayed" or "data may be old" label if data is older than a set limit. The refresh interval and the "too old" limit are set in one config place.
- Fund refresh only during US market hours (9:30 to 16:00 New York time, weekdays, skip holidays). Outside hours show the last close and say so.

PHASE 2: PAPER TRADING WITH A FAKE PORTFOLIO (Version 2)
Start only after Phase 1 works.

V2-5 Save portfolio
- Save in the browser (localStorage). No account. Show a short note: the portfolio stays only in this browser and device and can be lost if browser data is cleared.

----------------------------------------------------------------------

- ZCSH may have no usable data.
- Bid/ask for funds may stay empty.
- Hand-typed shares outstanding and fees go stale. Show the "as of" date next to each.

- Some exchange or data servers block US-based servers. If a request fails for this reason, say so.
