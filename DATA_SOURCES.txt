DATA SOURCES
Required by regulation-notes.txt: every data source, its terms link, and how it is used.

1. CoinGecko free API (IN USE: crypto table)
   - What: price, market value (market cap) and 24-hour volume for the top 20 tokens
     by 24-hour trading volume, plus the stablecoin category list.
   - How: a GitHub Actions job (.github/workflows/refresh-crypto.yml) calls it about
     every 15 minutes and saves data/latest.json. The web page never calls CoinGecko.
   - Key: none needed. An optional free "demo" key can be stored in the GitHub secret
     COINGECKO_DEMO_KEY. It is never written into project files.
   - Also used once a day for about 6 months of daily prices (data/history.json).
   - Attribution: the page shows "Data from CoinGecko" with a link.
   - Terms: https://www.coingecko.com/en/api_terms
   - Terms status: NOT YET READ IN FULL. The build session could not open the page
     (network blocked). Owner to review: public display, storing data, attribution.

2. Yahoo Finance via yfinance (IN USE: fund table)
   - What: price, volume today, total assets (shown as market value), yearly fee,
     bid and ask (kept only when within 1% of the price) for the 6 funds.
   - How: a GitHub Actions job (.github/workflows/refresh-funds.yml) runs every
     15 minutes on weekdays around US market hours and saves data/funds-latest.json.
     The web page never calls Yahoo.
   - Unofficial access that can break without warning. Owner accepted this for a
     private demo and chose Yahoo only, with no backup source.
   - Also used once a day for about 6 months of daily closing prices (data/history.json).
   - Terms: https://legal.yahoo.com/us/en/yahoo/terms/otos/index.html
   - Terms status: NOT YET READ.

   - Terms / info: https://www.frankfurter.app/
